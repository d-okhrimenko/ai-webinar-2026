# Start Action

1. Прочитай `context/current-feature.md` та перевір наявність активної фічі за правилами `SKILL.md`.
2. Визнач базову гілку за правилами репозиторію або попередніми вказівками користувача; якщо вона невідома, уточни її.
3. Створи від базової гілки гілку `feature/<slug>`: перетвори назву фічі з H1 на коротку допустиму назву гілки. Не перезаписуй сторонні незакомічені зміни. Якщо гілка вже існує, перевір, чи належить вона цій фічі: продовж роботу в ній або уточни неоднозначність.
4. Перемкнися на гілку фічі, виведи перелік цілей та почни їх реалізовувати.
