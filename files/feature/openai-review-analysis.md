# Аналіз відгуку через OpenAI
## Призначення
Реалізувати OpenAI-обробку для `POST /api/admin/reviews/{id}/analyze`.
## Критерії виконання
- Викликати OpenAI лише на сервері, отримати strict structured результат і зберегти поля аналізу разом із назвою провайдера та моделі.
## Граничні умови
- За відсутності відгуку повернути `404`, а за помилки OpenAI встановити `Failed`, не логуючи текст відгуку чи ключ.
