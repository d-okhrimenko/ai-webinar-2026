# Генерація відповіді через OpenAI
## Призначення
Реалізувати OpenAI-обробку для `POST /api/admin/reviews/{id}/draft-response`.
## Критерії виконання
- Викликати OpenAI лише на сервері, зберегти ввічливу чернетку відповіді разом із назвою провайдера та моделі.
## Граничні умови
- За відсутності відгуку повернути `404`, а за помилки OpenAI не змінювати наявну чернетку й не логувати текст відгуку чи ключ.
