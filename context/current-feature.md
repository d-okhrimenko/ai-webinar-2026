# Генерація відповіді через OpenAI

## Цілі

- Для `POST /api/admin/reviews/{id}/draft-response` реалізовано OpenAI-обробку виключно на сервері.
- Ввічлива згенерована чернетка відповіді зберігається разом із назвою провайдера та моделі.
- Не використовуй SDK, прості запити

## Нотатки

- За відсутності відгуку endpoint повертає `404`.
- Помилка OpenAI не змінює наявну чернетку й не призводить до логування тексту відгуку або API-ключа.

## Історія

- Реалізація AI-абстракції та тестової заглушки — додано незалежні AI-контракти, детермінований Stub-провайдер, серверні сценарії аналізу й генерації відповіді та кнопки в адмін-клієнті.
- Покращення адміністративного перегляду — локалізовано enum-значення та додано кольорові бейджі тональності й пріоритету; моделі згруповано за доменами.
- Базовий функціонал Reviews Assistant — реалізовано Web API, Angular-клієнт, PostgreSQL-міграції, JWT-автентифікацію, Swagger UI та адміністративні сценарії.
