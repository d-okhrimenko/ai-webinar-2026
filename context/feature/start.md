Реалізуй наступні сценарії

## Сценарій користувача

На публічній сторінці користувач заповнює форму:

- ім’я;
- email;
- текст відгуку.

Після відправлення відгук зберігається в базі даних, а користувач бачить повідомлення про успішне надсилання.

## Сценарій адміністратора

Адміністратор входить у систему та бачить список усіх відгуків.

Для кожного відгуку відображаються:

- ім’я автора;
- email;
- текст;
- дата створення;
- статус аналізу;
- тональність;
- пріоритет;
- категорія;
- короткий підсумок;
- ознака необхідності термінової реакції.

Адміністратор може відкрити картку відгуку та переглянути деталі. У картці має бути блок «Чернетка відповіді клієнту» і кнопка «Згенерувати відповідь». До підключення AI кнопка може бути неактивною або показувати зрозумілу заглушку: «AI-інтеграцію буде підключено пізніше».

Використовуй наступну модель даних

### Review

- `Id` — GUID.
- `AuthorName` — обов’язкове ім’я автора.
- `Email` — обов’язковий email.
- `Text` — обов’язковий текст відгуку.
- `CreatedAtUtc` — дата створення.
- `AnalysisStatus` — `Pending`, `Processing`, `Completed`, `Failed`.
- `Sentiment` — nullable: `Positive`, `Neutral`, `Negative`.
- `Priority` — nullable: `Low`, `Medium`, `High`, `Critical`.
- `Category` — nullable: наприклад `Praise`, `FeatureRequest`, `Bug`, `PaymentIssue`, `Support`, `Other`.
- `NeedsUrgentResponse` — nullable boolean.
- `Summary` — nullable рядок.
- `AiDraftResponse` — nullable рядок.
- `AnalyzedAtUtc` — nullable дата аналізу.

На підготовчому етапі AI-поля можуть бути порожніми, а статус аналізу — `Pending`.

## API

Публічні endpoints:

- `POST /api/reviews` — створити відгук.
- `GET /api/reviews/{id}/submission-status` — за потреби отримати статус відправлення.

Авторизовані admin endpoints:

- `POST /api/auth/login` — вхід адміністратора.
- `GET /api/admin/reviews` — список відгуків із фільтрами та сортуванням.
- `GET /api/admin/reviews/{id}` — детальна картка відгуку.
- `POST /api/admin/reviews/{id}/analyze` — endpoint створити заздалегідь, але до вебінару повертати заглушку.
- `POST /api/admin/reviews/{id}/draft-response` — endpoint створити заздалегідь, але до вебінару повертати заглушку.

## Angular-сторінки

- `/feedback` — публічна форма відгуку.
- `/login` — форма входу адміністратора.
- `/admin/reviews` — таблиця або список відгуків.
- `/admin/reviews/:id` — детальна картка відгуку.
