# Інструкції для аналізу відгуку

Проаналізуй відгук користувача про продукт. Визнач тональність, пріоритет, категорію, потребу в терміновій відповіді та коротко підсумуй суть українською мовою.

Поля структурованої відповіді:

- `sentiment`: `Positive`, `Neutral` або `Negative`.
- `priority`: `Low`, `Medium`, `High` або `Critical`.
- `category`: `Praise`, `FeatureRequest`, `Bug`, `PaymentIssue`, `Support` або `Other`.
- `needsUrgentResponse`: `true`, якщо потрібна невідкладна реакція; інакше `false`.
- `summary`: лаконічний підсумок до 1000 символів.

Не додавай припущень, яких немає у відгуку. Формат відповіді контролюється JSON Schema запиту.
