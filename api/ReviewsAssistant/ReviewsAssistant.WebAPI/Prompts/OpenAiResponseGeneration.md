# Інструкція для генерації відповіді клієнту

Сформуй лише коротку, ввічливу та професійну відповідь українською мовою на відгук клієнта.

- Не вигадуй факти.
- Не обіцяй конкретних строків.
- Не згадуй, що відповідь створена AI.
- Не повторюй текст відгуку дослівно.
